## Why CreatCV

Building a clean, ATS-friendly CV usually means fighting Word layouts or Canva exports that turn text into images.

**CreatCV** is a browser CV editor: fill in your profile, pick a preset, fine-tune colors and type, then export a selectable PDF (via print) or a Word document — no account required, data stays in your browser / your JSON file.

---

## Features

- Live **A4 preview** while you edit
- **40+** layout presets
- Section visibility, drag reorder, skill ratings, photo placement
- Export **Print / PDF** (selectable text) and **Word (.docx)**
- Save / Load JSON so you can keep multiple versions offline
- Starter template uses **placeholders only** — no sample personal data shipped

---

## Quick start

### Option A — use online (no install)

Open:

**https://kanaoda.github.io/CreatCV/**

Fill the form → pick a template → Print / Save as PDF or Export Word.

### Option B — run locally

```bash
git clone https://github.com/Kanaoda/CreatCV.git
cd CreatCV
npm install
npm run dev
```

Open **http://localhost:2999/**

```bash
npm run build   # output in dist/
```

---

## Privacy

- Runs entirely in the browser (no resume upload server)
- Default template is placeholder text (`[Your Full Name]`, etc.)
- Prefer **Save JSON** on your own machine if you store a real CV
